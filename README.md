# 杨欣润 · 个人设计作品集

中文个人作品集网站，包含界面与交互、视觉与数字体验、品牌设计以及 AIGC 视频。使用原始作品完整封面，保留直角、极窄间隙与克制动效，并适配电脑和手机。

## 网站内容

- 六个设计项目与七支视频／动态海报。
- 湖南卫视 KV、城市捉迷藏五位艺人的完整长图海报。
- 成都非遗广告策划正文与个人设计展示。
- 个人介绍、教育与实习经历、荣誉和联系方式。

## 发布

在仓库的 **Settings → Pages → Build and deployment** 中选择 **GitHub Actions**。推送至 `main` 分支后，工作流会自动发布网站。

预期访问地址：<https://yxr-yxr974.github.io/--->。实际发布状态以仓库 Actions 和 Pages 页面为准。

## 本地预览与更新

网站使用原生 HTML、CSS 和 JavaScript，不需要安装构建依赖。可直接打开 `index.html`，也可用静态网站服务器预览。

`index.html` 为首页，`project.html` 为作品详情；`style.css`、`refined.css` 控制视觉样式；`projects.js`、`videos.js` 管理项目和影片；`interactions.js` 处理渐入与阅读反馈。作品图片、视频和字体位于 `assets/`。
